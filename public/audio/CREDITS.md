# Credits

All sounds in this directory (and their sources in `audio-src/raw/`) are
**procedurally generated** by `scripts/generate-audio.mjs` — an offline,
seeded, dependency-free DSP renderer (noise, additive/modal synthesis, biquad
filters, Schroeder reverb, soft saturation).

No third-party audio, samples, or presets were used, downloaded, or embedded.
There are no license or copyright restrictions on these files; they are free
to use in streams and recordings, like the rest of this project (Apache-2.0).
